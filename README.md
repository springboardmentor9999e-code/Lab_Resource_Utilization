# LabSync Resource Manager

## Overview
LabSync Resource Manager is a web application that helps manage laboratory resources, equipment booking, and maintenance.

## Features
- Student Dashboard
- Staff Dashboard
- HOD Dashboard
- Admin Dashboard
- Equipment Management
- Booking System
- Maintenance Module
- AI Lab Assistant

## Tech Stack
- React
- TypeScript
- Vite
- Node.js

## Installation

```bash
npm install
npm run dev
```
