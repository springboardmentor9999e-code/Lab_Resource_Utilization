\# LabSync Resource Manager



\## Overview

LabSync Resource Manager is a web application for managing laboratory resources, equipment booking, maintenance requests, and role-based access.



\## Features

\- Student Dashboard

\- Staff Dashboard

\- HOD Dashboard

\- Admin Dashboard

\- Equipment Booking

\- Maintenance Management

\- AI Lab Assistant



\## Tech Stack

\- React

\- TypeScript

\- Vite

\- Node.js



\## Run the Project



```bash

npm install

npm run dev

```
